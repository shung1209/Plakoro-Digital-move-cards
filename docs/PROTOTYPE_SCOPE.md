# Prototype 0.1 Scope

## Included

- Existing Pokémon database discovery.
- Existing per-Pokémon move availability.
- Exactly-four-move loadout selection.
- Pokémon image preview where the V2.2 asset exists.
- English, Spanish, Japanese, and Traditional Chinese game-content localization.
- Card-specific translation preference before shared move-name translation.
- Large move dialog with Use / Cancel.
- Energy cost, printed damage, attack type, source/effect text, and Kyokoro outcome display.
- Simple current-session used-card history.
- Responsive Control-container layout suitable for desktop and Web foundations.

## Intentionally deferred

- Automatic damage/HP bookkeeping.
- Automatic Energy Dice and Kyokoro rolling.
- Condition/opcode execution.
- Persistent saved tabletop loadouts.
- Multiple players / multiple Pokémon at once.
- Card artwork reconstruction.
- Touch-specific landscape refinements.

## Suggested next increment

Prototype 0.2 should add saved favorites/loadouts and a dedicated visual card component using the existing element icons, while keeping "physical state" and "digital reference state" explicitly separate.
